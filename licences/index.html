Licences and open-source notices

Rivulet ships with no content. It uses the open-source software below.

FFmpeg (LGPL v2.1)

Rivulet uses three separately replaceable shared libraries built from FFmpeg for AC-3, E-AC-3 and DTS audio decoding: libavcodec, libavutil and libswresample, linked dynamically. The complete corresponding source, our patch and the build script for each release are in that release's source-offer bundle, listed on the releases page. The licence text is LICENSE.LGPLv2.1.

AndroidX Media3 and other Apache-2.0 components

Rivulet's playback uses AndroidX Media3 (ExoPlayer), and the app is built on other AndroidX, Kotlin, Dagger, Coil and OkHttp libraries, each licensed under the Apache License, Version 2.0. They are used unmodified, except for the FFmpeg decoder extension patch described in the source-offer bundle.
